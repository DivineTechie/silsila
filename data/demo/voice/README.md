# Demo voice clip

`story_mariam_ae_fatima.wav` (47 s, 16 kHz mono) is a SYNTHETIC voice: Microsoft Azure AI Speech neural
voice `ar-AE-FatimaNeural` (Emirati Arabic), generated with the team's own Azure subscription (UAE North)
from the fictional script `story_mariam_ae.txt` (Emirati dialect). The family and people are fictional.
It must be labelled "synthetic Emirati voice (Azure)" wherever it is played. Used to demonstrate
speech-to-family-tree with Jais-ASR (dialect setting AE); not used as evaluation evidence.
